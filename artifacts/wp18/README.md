# WP18 Usage visual evidence

These before/after PNGs are Chromium renders from the Usage layout harness, using synthetic fixture data and the same viewport dimensions. They are not captures of a live usage profile. The baseline is SpendSense main at `8afed8c` (0.6.12); after images show the WP18 branch. English and Simplified Chinese are included in light and dark themes. Narrow images use a 420 × 3600 viewport; wide images use 1240 × 2200.

The requested native Hermes capture could not be completed: the isolated `ssuat` profile was offline because its test backend was unavailable. The active native profile contained Usage data owned by the concurrent WP22 work, so it was left untouched.
